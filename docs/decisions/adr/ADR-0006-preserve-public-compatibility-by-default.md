# ADR-0006：默认保留公开兼容性

- 状态：已接受
- 日期：2026-05-17

## 背景

项目包含作者仍可能手动使用的研究工作流。在增量重构过程中（参见 ADR-0005），每个任务都可能意外破坏正在使用的已记录命令、公开 API、文件格式或 token 名称。

## 决策

保留已记录的命令、公开 API、文件格式、token 名称及Notebook可用性，除非选定的任务明确需要破坏性变更。

破坏性变更需满足：
1. 待办条目中有明确的范围说明。
2. 同一提交中包含 README 更新。
3. 在适当情况下提供迁移说明。

## 后果

- 各重构任务可独立执行，无需担心悄悄破坏整体工作流。
- 破坏性变更为可选项且有文档记录，而非意外副作用。
- 此约束适用于：CLI 设计、模块提取、数据转换和Notebook迁移。
